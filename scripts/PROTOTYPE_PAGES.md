# Public prototype pages

The canonical Workshop Designer and LinkedIn Conversation Engine routes contain
their complete introductory HTML, public demo markup, metadata and scripts.
They no longer fetch and rewrite an entire HTML document at runtime. The demo
interactions still run in JavaScript.

The root files `prototype-workshop-designer.html` and
`prototype-linkedin-posts.html` remain the editable demo sources. The existing
presentation transforms are retained in `scripts/prototype-page-loaders/` as
build inputs. They are executed locally by the generator with a local-file fetch
stub; the generator makes no network requests and does not execute demo scripts.

After changing either source or its presentation transform, run from the root:

```sh
node scripts/build_prototype_pages.mjs
node scripts/build_prototype_pages.mjs --check
```

Commit the source and generated canonical page together. Check that the public
demo interactions still work when making functional changes.

The sitemap is generated by `scripts/build_musings.py`. Its fixed page list
includes the Meaning Layer landing page, alongside the other public prototype
landing pages. Keep this list current when adding another public prototype.
